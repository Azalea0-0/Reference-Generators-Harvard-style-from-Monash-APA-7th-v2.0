# Reference Generators: Monash Harvard & APA 7th

Two free, browser-based reference generators:

- a combined Monash Harvard and APA 7th page;
- a standalone APA 7th page.

They generate references and in-text citations from supported links or DOIs. Each page lets the user choose between articles/journals and textbooks/books, then has a locally saved reference-list workspace that alphabetises entries and adds automatic numbering.

## Use

Open `index.html` for the combined generator, or `apa.html` for the standalone APA 7th generator. No account, server, or data upload is required for normal use; saved reference lists stay in the browser on the user's device.
